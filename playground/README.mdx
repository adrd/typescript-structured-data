# Property Access

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/1-objects/property-access" />

👨‍💼 We need to read and work with object properties. TypeScript ensures you
can only access properties that exist on an object.

There are two ways to access properties:

```ts
// Dot notation - most common
user.name

// Bracket notation - useful for dynamic keys
user['name']
```
